# 🚀 ИНСТРУКЦИЯ: Разработка v3.0 с Git ветками

## ❓ ГДЕ РАЗРАБАТЫВАТЬ v3.0?

### **✅ ПРАВИЛЬНО: В той же папке, но в другой Git ветке!**

```
📁 zvd_dxf_auto_working_copy/  ← ОДНА ПАПКА
   ├─ .git/
   │  ├─ main ← v2.0 (стабильная версия для цеха)
   │  └─ feature/ai-recommendations ← v3.0 (разработка)
   │
   ├─ components/
   └─ ...
```

### **❌ НЕПРАВИЛЬНО: Создавать новую папку**

```
❌ zvd_dxf_auto_working_copy_v2/
❌ zvd_dxf_auto_working_copy_v3/
❌ zvd_dxf_auto_working_copy_new/
```

**Проблемы:**
- Дублирование всего кода
- Сложно синхронизировать изменения
- Занимает в 2 раза больше места
- Теряется история изменений

---

## 🌿 ЧТО ТАКОЕ GIT ВЕТКИ?

### **Простая аналогия:**

Представьте дерево:
```
            main (ствол) ← v2.0 стабильная
             │
             │ 
       ┌─────┴─────┐
       │           │
  feature/v3   другие
   (ветка)     ветки
   
   v3.0
   разработка
```

**Git ветки = параллельные версии кода:**
- **main** - стабильная версия (v2.0) для цеха
- **feature/ai-recommendations** - экспериментальная (v3.0)

**Можно переключаться между ними мгновенно!**

---

## 📋 ПОШАГОВАЯ ИНСТРУКЦИЯ

### **ШАГ 1: Создать ветку для v3.0**

```bash
# Убедитесь, что вы в main
git checkout main

# Создать новую ветку для v3.0 и переключиться на нее
git checkout -b feature/ai-recommendations

# Проверить текущую ветку
git branch
# * feature/ai-recommendations  ← звездочка показывает текущую ветку
#   main
```

**Теперь вы в ветке v3.0!** Все изменения будут только здесь.

---

### **ШАГ 2: Разработка v3.0**

```bash
# Вы в ветке feature/ai-recommendations

# Создайте новые файлы:
# components/ai_optimizer.py
# components/projects_database.py
# components/detail_recommender.py

# Измените существующие:
# unfolding_area_calculator/gui_calculator_enhanced.py (добавить AI блок)

# Работайте как обычно!
```

**Важно:** v2.0 (в ветке main) остается нетронутым!

---

### **ШАГ 3: Сохранение изменений**

```bash
# После каждого значимого изменения:

# Добавить файлы
git add .

# Сохранить изменения
git commit -m "v3.0: Added AI optimizer module"

# Загрузить на GitHub (опционально)
git push origin feature/ai-recommendations
```

**Теперь на GitHub будет 2 ветки:**
- `main` - v2.0 (стабильная)
- `feature/ai-recommendations` - v3.0 (разработка)

---

### **ШАГ 4: Переключение между версиями**

```bash
# РАБОТАТЬ НАД v3.0:
git checkout feature/ai-recommendations
# Теперь видите код v3.0
# Можете менять, тестировать

# ВЕРНУТЬСЯ К v2.0 (например, исправить баг):
git checkout main
# Теперь видите код v2.0
# Можете исправить баг, сделать коммит

# СНОВА К v3.0:
git checkout feature/ai-recommendations
```

**Магия:** Одна папка, но разные версии кода!

---

### **ШАГ 5: Когда v3.0 готова - слияние**

```bash
# Переключиться на main
git checkout main

# Слить v3.0 в main
git merge feature/ai-recommendations

# Создать тег v3.0
git tag v3.0

# Загрузить на GitHub
git push origin main --tags
```

**Теперь v3.0 стала основной версией!**
