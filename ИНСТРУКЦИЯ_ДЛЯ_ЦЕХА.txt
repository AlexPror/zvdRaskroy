🚀 УСТАНОВКА (1 РАЗ)
═══════════════════════════════════════════════════════════

1. Скопируйте файл "Раскрой_Деталей_v2.0.exe" на компьютер
   Рекомендуемое место: C:\Программы\Раскрой\

2. Создайте ярлык на рабочем столе:
   • Правой кнопкой на .exe файл
   • Отправить → Рабочий стол (создать ярлык)
   • Переименуйте ярлык: "Раскрой Деталей"

3. Готово! Python НЕ нужен, всё уже внутри программы.

═══════════════════════════════════════════════════════════
📋 КАК ПОЛЬЗОВАТЬСЯ (3 ШАГА)
═══════════════════════════════════════════════════════════

ШАГ 1: ЗАПУСТИТЬ ПРОГРАММУ
   • Двойной клик по ярлыку "Раскрой Деталей"
   • Первый запуск может быть медленным (5-10 сек)

ШАГ 2: ЗАГРУЗИТЬ ФАЙЛЫ
   • Нажмите "🔍 Загрузить файлы DXF"
   • Выберите папку с проектом (например: ZVD.LITE.150.200.3000)
   • Программа автоматически загрузит файлы и рассчитает площади
   • Проверьте таблицу (зеленые ячейки = автоматически)

ШАГ 3: ЗАПУСТИТЬ РАСКРОЙ
   • Нажмите "🚀 Запустить раскрой и создать отчеты"
   • Подождите 2-3 секунды
   • PDF и Excel откроются автоматически!
   • Готово!

═══════════════════════════════════════════════════════════
📁 ГДЕ СОХРАНЯЮТСЯ ОТЧЕТЫ?
═══════════════════════════════════════════════════════════

Пример:
C:\Проекты\ZVD.LITE.150.200.3000 А-021025-1225\
  └─ Лазерная резка\
     └─ Отчеты_Раскроя\  ← ЗДЕСЬ!
        ├─ Раскрой_..._20251021_201000.pdf
        └─ Раскрой_..._20251021_201000.xlsx

♻️ УЧЕТ ОБРЕЗКОВ (важно!)
═══════════════════════════════════════════════════════════

ПОСЛЕ РЕЗКИ:
1. Откройте Excel файл, лист "Обрезки"
2. Найдите обрезки на листе металла
3. Маркером пометьте: W-001, W-002, W-003...
4. Пригодные обрезки (✓ Да) → в отдельную зону
5. Мелкие (✗ Нет) → можно утилизировать

ПЕРЕД НОВЫМ ЗАКАЗОМ:
Проверьте Excel файлы старых заказов - может есть подходящий обрезок!

═══════════════════════════════════════════════════════════
⚠️ ЧАСТЫЕ ПРОБЛЕМЫ
═══════════════════════════════════════════════════════════

ПРОБЛЕМА: Программа не запускается
РЕШЕНИЕ: 
   • Windows может блокировать .exe из интернета
   • Правой кнопкой → Свойства → Разблокировать → ОК
   • Запустите снова

ПРОБЛЕМА: Антивирус блокирует
РЕШЕНИЕ:
   • Добавьте .exe в исключения антивируса
   • Это безопасный файл (ложное срабатывание)

ПРОБЛЕМА: Папка не распознается
РЕШЕНИЕ:
   • Проверьте название папки
   • Должно быть: ZVD.LITE.150.200.3000 А-021025-1225
   • Обязательно должны быть цифры H.W.L

ПРОБЛЕМА: Размеры неправильные
РЕШЕНИЕ:
   • Откройте DXF в AutoCAD
   • Удалите лишние объекты (текст, размеры, вспомогательные линии)
   • Оставьте только контур детали
