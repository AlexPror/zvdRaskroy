  ☐ Установить shapely: pip install shapely

  ☐ Протестировать на 1 файле
  ☐ Отправить примеры DXF → доработка парсера

  ☐ Подготовить стеллажи для обрезков
  ☐ Решить вопрос маркировки (этикетки/маркер)

  ☐ Обучить операторов (30 минут)
  ☐ Пробная резка с учетом обрезков

НЕДЕЛЯ 3: Накопление базы
  ☐ Импортировать ВСЕ раскрои из CypCut
  ☐ Маркировать обрезки
  ☐ Складывать на стеллаж
  ☐ Цель: 30+ обрезков в базе

НЕДЕЛЯ 4: Первое использование
  ☐ Проверять базу перед новым проектом
  ☐ Использовать 5-10 обрезков
  ☐ Посчитать реальную экономию
  ☐ Презентация результатов

📊 МЕТРИКИ УСПЕХА (KPI)
================================================================================

1. Количество обрезков в базе:
   - Через 1 месяц: 50 шт
   - Через 3 месяца: 200 шт

2. Процент переиспользования:
   - Через 1 месяц: 10%
   - Через 3 месяца: 30%
   - Через год: 40%+

3. Экономия в месяц:
   - Через 1 месяц: 10,000 руб
   - Через 3 месяца: 25,000 руб стабильно

4. Площадь обрезков в наличии:
   - Стабильный запас: 5-10 м²

💻 БЫСТРЫЙ СТАРТ (ПРЯМО СЕЙЧАС)

   pip install shapely

   - Взять любой DXF из CypCut

   - Проверить База_обрезков.xlsx

4. ВЕБ-ИНТЕРФЕЙС (1 минута):
   
   python waste_database_viewer.py
   
   Откроется http://localhost:8080
