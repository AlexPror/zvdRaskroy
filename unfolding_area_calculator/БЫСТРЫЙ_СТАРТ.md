# ⚡ БЫСТРЫЙ СТАРТ - Умный раскрой

## 🚀 **3 ПРОСТЫХ ШАГА:**

### 1️⃣ Запустите программу
```bash
python gui_calculator_enhanced.py
```
Или двойной клик на: `ЗАПУСК_V2_УЛУЧШЕННАЯ.bat`

### 2️⃣ Загрузите и настройте
1. **Выберите папку** с DXF файлами
2. **Нажмите** "Загрузить файлы"
3. **Укажите количество** каждой детали в желтых полях

### 3️⃣ Получите результат
**Нажмите:** `🚀 АВТОМАТИЧЕСКИЙ РАСКРОЙ`

**Готово!** Программа покажет:
- 📦 Сколько листов нужно
- 📊 Процент использования
- 📄 PDF с раскладкой
- 📊 Excel с обрезками

## ⚙️ **НАСТРОЙКИ:**

### Желтые поля (количество):
- Вводите **количество деталей** вручную
- Программа автоматически пересчитывает итоги
- Для больших серий используйте кнопку **"Одинаковое количество"**

### Что учитывается автоматически:
- ✅ Зазор резки **5 мм**
- ✅ Поворот деталей **на 90°**
- ✅ Лист **2500×1250 мм**
- ✅ Комбинирование **больших и маленьких**

## 📄 **РЕЗУЛЬТАТЫ:**

## ❓ **ЧАСТЫЕ ВОПРОСЫ:**

**В: Как указать количество для серии?**  
О: В желтых полях введите нужное число (например, 20)

**В: Как детали размещаются?**  
О: Автоматически! Программа пробует 3 алгоритма и выбирает лучший

**В: Можно ли изменить размер листа?**  
О: Стандарт 2500×1250 мм. Для изменения редактируйте код в `smart_nesting_optimizer.py`

**В: Учитывается ли зазор резки?**  
О: Да, автоматически 5 мм между деталями

**В: Поворачиваются ли детали?**  
О: Да, на 90° для лучшего размещения

## 🆘 **ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ:**

### Ошибка "rectpack не найден":
```bash
pip install rectpack
```

### Не загружаются файлы:
- Проверьте, что файлы в формате **.dxf**
- Убедитесь, что файлы экспортированы правильно из КОМПАС/SolidWorks

### Программа не запускается:
```bash
pip install -r requirements.txt
```
