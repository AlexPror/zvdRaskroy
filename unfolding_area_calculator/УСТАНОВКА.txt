ДЛЯ ЦЕХА - ПОШАГОВАЯ ИНСТРУКЦИЯ

═══════════════════════════════════════════════════════════════

ШАГ 1: Установите Python
───────────────────────────────────────────────────────────────

1. Скачайте Python 3.11 или новее:
   https://www.python.org/downloads/

2. При установке ОБЯЗАТЕЛЬНО поставьте галочку:
   ☑ Add Python to PATH

3. Установите → Готово

═══════════════════════════════════════════════════════════════

ШАГ 2: Установите зависимости
───────────────────────────────────────────────────────────────

1. Откройте папку "unfolding_area_calculator"

2. В адресной строке напишите: cmd  (нажмите Enter)

3. В открывшемся окне напишите:
   pip install -r requirements.txt

4. Дождитесь установки

═══════════════════════════════════════════════════════════════

ШАГ 3: Запустите программу
───────────────────────────────────────────────────────────────

Двойной клик по файлу:
   gui_calculator.py

Или в командной строке:
   python gui_calculator.py

═══════════════════════════════════════════════════════════════

ГОТОВО! Программа запущена!

═══════════════════════════════════════════════════════════════

ИСПОЛЬЗОВАНИЕ:

1. Выберите папку с развертками DXF/CDW
2. Нажмите "Загрузить файлы"
3. Укажите количество каждой детали (двойной клик)
4. Экспортируйте в PDF или Excel

═══════════════════════════════════════════════════════════════

ВНИМАНИЕ:

• Для DXF файлов (SolidWorks) - работает без КОМПАС
• Для CDW файлов (КОМПАС) - нужен установленный КОМПАС-3D
