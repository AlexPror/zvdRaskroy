# 🎨 Утилита расчета площадей v2.0 (УЛУЧШЕННАЯ)

## Что нового в версии 2.0?

### ✨ НОВЫЕ ВОЗМОЖНОСТИ:

1. **Оптимизация раскроя** (Rectpack)
   - Автоматический расчет оптимальной укладки деталей
   - Уменьшение обрезков на 10-20%
   - Расчет количества листов

2. **Визуализация раскладки** (PDF)
   - Цветная схема размещения деталей на листах
   - Размеры каждой детали
   - Таблица обрезков с номерами

3. **Учет обрезков**
   - Каждому обрезку присваивается номер (W-001, W-002...)
   - Автоматическое добавление в Excel базу
   - Маркировка для цеха

4. **База данных обрезков** (Excel)
   - Накопительная база для всех проектов
   - Поиск подходящих обрезков
   - Отслеживание использования

5. **Интерактивный редактор раскроя** (НОВОЕ!)
   - **Drag & Drop** - перетаскивание деталей мышью
   - **Визуальный контроль** - видите результат сразу
   - **Гибкое редактирование** - перемещайте детали для оптимизации
   - **Авторазмещение** - кнопка для быстрого старта

## 📖 Инструкция

### Обычный расчет (как раньше):

1. Выберите папку с DXF
2. Нажмите "Загрузить файлы"
3. Укажите количества (двойной клик)
4. Экспорт в PDF или Excel

### НОВОЕ: Оптимизация раскроя:

1. После загрузки файлов
2. Нажмите **"⚙️ Оптимизировать раскрой + создать PDF с обрезками"**
3. Программа создаст:
   - PDF с цветной раскладкой
   - Таблицу обрезков с номерами
   - Excel базу обрезков
   
4. **В цехе:**
   - Распечатайте PDF
   - После резки маркером пометьте обрезки (W-XXX)
   - Сложите в зону "ОБРЕЗКИ"

### НОВОЕ: Интерактивное редактирование:

1. После загрузки файлов
2. Нажмите **"✏️ Редактировать раскрой (Drag & Drop)"**
3. **В редакторе:**
   - Перетащите детали из списка на лист
   - Перемещайте размещенные детали для оптимизации
   - Используйте "Авторазмещение" для быстрого старта
   - Нажмите "Сохранить раскрой" когда закончите

## 💡 Использование обрезков

### Поиск обрезка:

1. Открыть **База_обрезков.xlsx**
2. Фильтр: Статус = "В наличии"
3. Найти подходящий размер
4. Взять обрезок из зоны (по номеру W-XXX)
5. Вырезать нужную деталь
6. Обновить статус: "Использован"

- Переиспользование 30% обрезков
