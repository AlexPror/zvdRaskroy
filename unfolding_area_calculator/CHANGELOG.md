## Использование

### 1. Загрузите файлы
```
[🔍 Загрузить файлы]
```

### 2. Введите количества
Просто кликните в поле и введите число:
```
Корпус:   [1]  ← Tab
Стенка:   [2]  ← Tab
Распорка: [3]  ← Enter
```

### 3. Итого обновляется автоматически!
```
ИТОГО: 1.0800 м² | С зазорами: 1.1200 м² (+3.7%)
```
