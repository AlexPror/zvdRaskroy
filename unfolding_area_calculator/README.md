# 📐 Утилита расчета площадей разверток

## Универсальная программа для цеха

**Версия:** 1.0  
**Дата:** 17.10.2025

---

## 🎯 Назначение

**Для кого:** Цех (производство)

**Что делает:**
- Считает площади разверток из DXF или CDW
- Ручной ввод количества каждой детали
- Рассчитывает площадь с зазорами для резки
- Экспорт в PDF или Excel

**Поддерживаемый формат:**
- ✅ **DXF** (универсальный формат из любых CAD: SolidWorks, КОМПАС, AutoCAD, Inventor)

---

## 📦 Установка

### 1. Установите Python 3.11+

Скачайте с [python.org](https://www.python.org/downloads/)

### 2. Установите зависимости

```bash
cd unfolding_area_calculator
pip install -r requirements.txt
```

---

## 🚀 Использование

### Запуск программы:

```bash
python gui_calculator.py
```

### Инструкция:

1. **Выберите папку** с развертками (DXF или CDW)
2. **Введите номер заказа** (опционально)
3. **Нажмите "Загрузить файлы"**
4. **Укажите количество** для каждой детали:
   - Двойной клик по строке
   - Или кнопка "Изменить количество"
5. **Экспортируйте результат:**
   - PDF для отчета
   - Excel для расчетов

---

## 📊 Что считает?

### Площади:

1. **Чистая площадь** — размер самой детали
2. **С зазорами** — с учетом резки (+5 мм между деталями, +10 мм от краев)

### Зазоры:

```
Между деталями: 5 мм (ширина реза)
От краев листа: 10 мм (технологический отступ)
```

### Формула:

```
Площадь с зазорами = (Ширина + 5) × (Высота + 5) / 1,000,000
```

**Увеличение:** обычно +3-5%

## 💡 Рекомендации

### Вариант A: Программа в цехе ⭐ РЕКОМЕНДУЮ

**Как работает:**
1. Конструкторы кладут развертки в общую папку
2. Мастер цеха запускает программу
3. Указывает количества
4. Получает отчет (PDF/Excel)

**Преимущества:**
- ✅ Централизованный контроль
- ✅ Единый формат отчетов
- ✅ Не нужно обучать всех
- ✅ Проще обновлять

**Структура папок:**
```
\\Server\Производство\Заказы\
├── А-12158-1544\
│   ├── Развертки\
│   │   ├── Корпус.dxf
│   │   ├── Стенка.dxf
│   │   └── ...
│   └── Расчет_площадей_А-12158-1544.pdf  ← Результат
└── ...
```

---

### Вариант B: Раздать конструкторам

**Как работает:**
1. Каждый конструктор устанавливает программу
2. После создания разверток → считает площади
3. Отправляет PDF в цех

**Преимущества:**
- ✅ Ответственность конструктора
- ✅ Проверка на этапе проектирования

**Недостатки:**
- ⚠️ Нужно обучать всех
- ⚠️ Разные версии программы
- ⚠️ Могут забыть посчитать
