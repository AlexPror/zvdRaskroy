- Светлый: `#64B5F6` (голубой)
- Акцент: `#FF6F00` (оранжевый)

## 🎨 Элементы дизайна

### 1. Шапка
```
📐 ZVD Площади  ← Крупный шрифт (16pt, жирный)
Расчет площадей разверток для производства  ← Подзаголовок
────────────────────────────────  ← Разделитель
```

### 2. Кнопка загрузки
```
╔═══════════════════════════════════════╗
║ 🔍 Загрузить файлы и рассчитать      ║  ← Синяя (#1976D2)
╚═══════════════════════════════════════╝    Белый текст
                                             Крупный шрифт
                                             Курсор "hand"
```

### 3. Заголовки таблицы
```
┌──┬──────────┬────────┬────────┬────────┬────────┬────────┐
│№ │ Файл     │Ширина  │Высота  │Площадь │ Кол-во │ Итого  │
│  │          │  мм    │  мм    │  м²    │   шт   │  м²    │
```
- Фон: Синий `#1976D2`
- Текст: Белый
- Жирный шрифт

### 4. Строки данных
```
Четные: Фон #F5F5F5 (светло-серый)
Нечетные: Фон #FFFFFF (белый)
```

### 5. Поля ввода количества
```
[ 2 ]  ← Желтый фон (#FFF9C4)
       Жирный шрифт (10pt)
       Рамка (bd=2)
```

**Выделяются** для привлечения внимания!

### 6. Колонка "Итого"
```
0.3600  ← Синий текст (#0D47A1)
        Жирный шрифт
```

### 7. Блок итогов
```
╔═══════════════════════════════════════════════════════╗
║ ИТОГО: 1.0800 м² | С зазорами: 1.1200 м² (+3.7%)    ║
╚═══════════════════════════════════════════════════════╝
```
- Фон: Светло-голубой `#E3F2FD`
- Текст: Синий `#1976D2`
- Жирный шрифт (12pt)
- Рамка выпуклая

### 8. Кнопки экспорта
```
[📄 Экспорт в PDF]  [📊 Экспорт в Excel]
```
- Крупные (width=22)
- Синий текст
- Стиль Accent

## 📏 Размеры

**Окно:**
- Минимум: 850×600
- По умолчанию: 75% экрана (макс 1050×750)
- Центрируется автоматически

**Шрифты:**
- Заголовок: Arial 16pt Bold
- Подзаголовок: Arial 10pt
- Таблица: Arial 9pt
- Поля ввода: Arial 10pt Bold
- Итоги: Arial 12pt Bold

**Отступы:**
- Секции: padding 12px
- Между элементами: 5-10px
- В таблице: 1-2px

## ✨ Фишки дизайна

### 1. Желтые поля ввода
**Почему:** Сразу видно где вводить!
```
[  2  ]  ← Желтый фон
```

### 2. Чередующиеся строки
**Почему:** Легче читать таблицу
```
Строка 1: Белый
Строка 2: Серый
Строка 3: Белый
```

### 3. Синяя кнопка загрузки
**Почему:** Главное действие выделено
```
🔍 Загрузить  ← Крупная, синяя, с курсором-рукой
```

### 4. Итоги в рамке
**Почему:** Важная информация выделена
```
╔════════════════════════════╗
║ ИТОГО: X.XXXX м²          ║  ← Голубой фон
╚════════════════════════════╝
```
