# 🔍 Сравнение вариантов размещения утилиты

## Дата: 17.10.2025

---

## 📊 Вариант A: Программа в ЦЕХЕ ⭐ РЕКОМЕНДУЮ

### Как работает:

```
Конструктор 1 (SolidWorks)
    ↓ Экспорт DXF
    ↓
\\Server\Производство\Заказы\А-12158\Развертки\
    ↑
Конструктор 2 (КОМПАС)
    ↓ CDW или DXF
    ↓
[Папка с развертками готова]
    ↓
Мастер цеха
    ↓ Запускает утилиту
    ↓ Указывает количества
    ↓
PDF/Excel отчет → Заказ листов
```

### Преимущества:

✅ **Централизованный контроль**
   - Один человек отвечает за расчеты
   - Единый формат отчетов

✅ **Не нужно обучать всех**
   - Конструкторы просто кладут файлы
   - Знать программу нужно только мастеру

✅ **Проще обновлять**
   - Одна копия программы
   - Обновление в одном месте

✅ **Меньше ошибок**
   - Специалист знает программу
   - Проверяет перед производством

✅ **Гибкость**
   - Можно корректировать количества
   - Можно пересчитать при изменениях

### Недостатки:

⚠️ **Дополнительный шаг**
   - Мастер должен запустить программу
   - Нужно указывать количества вручную

⚠️ **Зависимость от мастера**
   - Если забыл → нет расчета

## 📊 Вариант B: Раздать КОНСТРУКТОРАМ

### Как работает:

```
Конструктор 1 (SolidWorks)
    ↓ Создал развертки
    ↓ Запустил утилиту
    ↓ Указал количества
    ↓ Создал PDF
    ↓
\\Server\Производство\Заказы\А-12158\
    ├── Развертки\
    └── Расчет_площадей.pdf  ← Готово!

Конструктор 2 (КОМПАС)
    ↓ То же самое
    ↓
PDF готов
```

### Преимущества:

✅ **Автоматизация**
   - Конструктор сразу создает отчет
   - Нет дополнительных шагов в цехе

✅ **Ответственность конструктора**
   - Проверка на этапе проектирования
   - Меньше ошибок в производстве

✅ **Быстрее**
   - Не нужно ждать цех
   - Отчет готов сразу

### Недостатки:

❌ **Нужно обучить ВСЕХ**
   - Каждый конструктор должен знать программу
   - Требуется время на обучение

❌ **Разные версии**
   - У каждого своя копия
   - Сложно обновлять

❌ **Могут забыть**
   - Человеческий фактор
   - Отчет может отсутствовать

❌ **Поддержка**
   - Нужно помогать каждому
   - Больше обращений за помощью

## 📁 Структура для Варианта A

### На сервере:

```
\\Server\Производство\
├── Утилиты\
│   └── unfolding_area_calculator\  ← Программа ЗДЕСЬ
│       ├── ЗАПУСК.bat
│       ├── gui_calculator.py
│       ├── area_calculator.py
│       └── requirements.txt
│
└── Заказы\
    ├── А-12158-1544\
    │   ├── Развертки\               ← Конструкторы кладут сюда
    │   │   ├── Корпус.dxf
    │   │   ├── Стенка.dxf
    │   │   └── ...
    │   └── Расчет_площадей.pdf      ← Результат
    │
    └── А-12159-1600\
        └── ...
```

### Инструкция для конструкторов:

```
1. Создали развертки (SolidWorks или КОМПАС)
2. Экспортировали в DXF
3. Положили в: \\Server\Производство\Заказы\<номер>\Развертки\
4. Сообщили мастеру цеха

ГОТОВО! Остальное делает мастер.
```

### Инструкция для мастера цеха:

```
1. Открыть: \\Server\Производство\Утилиты\unfolding_area_calculator\
2. Запустить: ЗАПУСК.bat
3. Выбрать папку заказа: \\Server\...\Заказы\А-12158\Развертки\
4. Указать количества деталей
5. Создать PDF
6. Заказать листы по площади "С зазорами"
```
