## 🚀 Передача в цех - 3 шага

### Вариант А: Сетевой диск (рекомендуется)

```
1. Скопируйте:
   dist\ZVD_Ploshchadi.exe
   
2. На сетевой диск:
   \\Server\Производство\Утилиты\ZVD_Ploshchadi.exe
   
3. На рабочем столе мастера создайте ярлык:
   ПКМ → Создать ярлык → Указать путь к EXE
```

### Вариант Б: Прямая установка

```
1. Скопируйте EXE на рабочий стол мастера
2. Переименуйте ярлык: "ZVD - Площади"
3. Двойной клик для проверки
```

### Вариант В: USB флешка

```
1. Скопируйте EXE на флешку
2. Отдайте флешку мастеру
3. Мастер копирует на свой компьютер
```

## 🐛 Решение проблем

### Программа не запускается:

1. Проверьте 64-bit Windows
2. Запустите от имени администратора
3. Добавьте в исключения антивируса

### Не находит DXF:

1. Проверьте расширение файла (`.dxf`)
2. Попробуйте пересохранить из CAD
3. Убедитесь что путь без спецсимволов

### Некорректные габариты:

1. Проверьте что DXF содержит только контур развертки
2. Убедитесь что единицы измерения в DXF - миллиметры
3. Удалите размеры и примечания из DXF (оставьте только геометрию)
