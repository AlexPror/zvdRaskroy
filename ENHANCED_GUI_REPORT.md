## Технические детали

### Компоненты системы
1. **`CleanProjectGUI`** - основное GUI приложение
2. **`DrawingsUpdateWorker`** - отдельный поток для обновления чертежей
3. **`DrawingExporter`** - компонент экспорта чертежей
4. **`ProjectProcessor`** - оркестратор всех операций

### Поддерживаемые форматы
- **BMP**: Основной формат для высокого качества
- **PNG**: Альтернативный формат с сжатием
- **Разрешение**: 300 DPI
- **Цветность**: 24-битный цвет

### Исключения
- **Чертежи разверток**: Автоматически исключаются из экспорта
- **Ключевые слова**: "развертка", "развёртка", "unfold"

## Использование

### Основной workflow
1. **Создание проекта**: Нажмите "Создать проект"
2. **Активация кнопки**: После успешного создания кнопка "Обновить чертежи" станет активной
3. **Обновление чертежей**: Нажмите "Обновить чертежи" в любое время для переэкспорта
4. **Выбор формата**: Используйте выпадающий список для выбора BMP или PNG
